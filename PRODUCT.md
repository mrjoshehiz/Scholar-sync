# ScholarSync
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Students organizing scholarship applications and adapting their own writing to each opportunity.
## Product Purpose
Track scholarships, compare eligibility, tailor authentic applications, and see deadline/status notifications.
## Capabilities and Constraints
Durable user-specific profile, tracker, notes, checklist, drafts, reminders and notification history. Gemini integration needs an API key; keys entered in the UI remain in memory. Browser notifications work while the app is open; calendar export provides progressive alarms through a calendar client. Scholarships are user-supplied. Samples must be visibly labelled fictional. Signed-out visitors can explore an ephemeral sample workspace; preview edits are never persisted. Matching is an explainable alignment score, never an admission prediction. Exact sponsor deadlines and timezone must be verified.
## Brand Commitments
ScholarSync. User selected the Talboost dashboard reference: dark surfaces, horizontal navigation, varied panel composition and warm amber accents. Preserve the request against generic AI visual signatures, glows, decorative badges, or sparkles.
## Product Principles
Protect ownership of user data. Preserve input after errors. Do not invent profile facts. Show uncertainty about eligibility.
